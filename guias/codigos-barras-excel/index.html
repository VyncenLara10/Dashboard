Cómo crear códigos de barras desde Excel paso a paso

Si tienes una tienda o un pequeño inventario, colocar una etiqueta legible en cada artículo ayuda a identificar productos rápidamente. Con Barras Studio puedes transformar una tabla de Excel o CSV en etiquetas imprimibles, sin introducir los productos uno por uno.

1. Prepara tu hoja de Excel

Incluye una columna con el nombre del producto y otra con un código único para cada artículo. Puedes añadir precio y cantidad. Evita códigos duplicados si corresponden a productos distintos, y conserva los ceros iniciales usando formato de texto.

2. Elige un tipo de código

Code 128 acepta letras y números y suele servir para códigos internos como CAM-001. EAN-13 requiere una numeración específica y un dígito de control; no inventes un EAN si pretendes utilizar una identificación comercial GS1. QR puede contener enlaces o identificadores, pero necesita un lector 2D.

3. Revisa la vista previa

Selecciona Carta o A4 y el número de etiquetas por hoja. Mantén el nombre y el código impreso debajo de las barras para que una persona identifique el artículo sin escáner. Si el código es largo, usa un tamaño de etiqueta más grande.

4. Descarga e imprime

Descarga el PDF y en el visor de impresión selecciona escala real, 100%. Imprime una página de prueba y escanea varios códigos antes de imprimir todo el inventario. Evita fondos de bajo contraste o papel que borre las líneas.

5. Conecta con el inventario

El generador produce etiquetas y Barras Studio incluye un módulo local de existencias. Para una caja comercial con varios usuarios se necesitaría persistencia centralizada y control de permisos.
